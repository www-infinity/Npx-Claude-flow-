How it works

  1. 01

    Initialise the hive

    Run npx claude-flow@alpha hive init to bootstrap your agent cluster with the topology and agent count of your choice.

  2. 02

    Write your worker

    Use the claude_worker.py template to define exactly what each agent should do — from repo analysis to code generation.

  3. 03

    Run and collect results

    Execute your worker script. Agents fan out across the workload in parallel and return structured insights.

Quickstart

Up and running in under two minutes.

1. Bootstrap the hive 
npx claude-flow@alpha hive init --topology mesh --agents 5
2. Set your API key 
export ANTHROPIC_API_KEY="sk-ant-..."
3. Run the worker 
python claude_worker.py
